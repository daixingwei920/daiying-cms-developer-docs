## 发布流程

1. 开发扩展。
2. 本地测试。
3. 生成符合 Market 标准的扩展包。
4. 提交 Daiying 官方审核。
5. AI / 自动安全检查。
6. 官方人工审核。
7. 审核通过。
8. 发布。
9. 商业扩展可按政策购买商业授权码。
